# BG Calculators

Безплатни онлайн калкулатори за българския пазар.

## Проект

Статичен сайт с калкулатори за България, изграден с HTML, CSS и vanilla JavaScript. Без бекенд, без база данни, без платени библиотеки.

## Калкулатори

- **Нетна заплата** - Изчисляване на нетна от брутна заплата с осигуровки и данъци
- **ДДС Калкулатор** - Изчисляване на ДДС за стандартна и намалена ставка
- **Данък върху наем** - Изчисляване на данък върху наемен доход

## Актуализация на ставките

Всички ставки са в `js/rates.js`. Преди публикуване:

### Автоматична проверка (Python)

1. Инсталирай зависимостите:
```bash
pip install -r requirements.txt
```

2. Стартирай скрипта за проверка:
```bash
python update_rates.py
```

Това ще генерира отчет `rate_verification_report.txt` с информация какво е проверено и какво нуждае от ръчна проверка.

### Бърза проверка (Отваряне на сайтове)

**Windows:**
```bash
verify_rates.bat
```

**Linux/macOS:**
```bash
chmod +x verify_rates.sh
./verify_rates.sh
```

Това ще отвори официалните сайтове в браузъра и ще покаже чеклист за проверка.

### Ръчна проверка

1. Провери актуалните ставки на:
   - НАП: https://nap.bg/
   - НОИ: https://www.noi.bg/
   - Министерство на финансите: https://www.minfin.bg/
2. Актуализирай стойностите в `js/rates.js`
3. Обнови датата на проверка в коментара

### Стойности за проверка

Преди публикуване, проверете:
- Минимален осигурителен доход за 2026 (в EUR)
- Максимален осигурителен доход за 2026 (в EUR)
- Такса смет по общини за 2026 (в EUR)
- Детски добавки (ако се прилагат)

## Публикуване

Инструкции за GitHub Pages:

1. Създай репозитория в GitHub
2. Качи файловете
3. В Settings > Pages избери main branch
4. Сайтът ще бъде достъпен на: https://yourusername.github.io/bg-calculators/

**ВАЖНО:** Промени `yourusername` с твоя GitHub username в:
- `sitemap.xml`
- `robots.txt`
