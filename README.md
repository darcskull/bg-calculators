# BG Calculators

Безплатен статичен сайт с калкулатори за българския пазар. Използва HTML, CSS и vanilla JavaScript; няма външни runtime зависимости, бекенд или база данни.

## Калкулатори

- **Нетна заплата** — ориентировъчна сметка за стандартен трудов договор. Осигурителният праг и други индивидуални случаи могат да променят резултата.
- **ДДС** — математическо добавяне или извличане на избрана ставка. Калкулаторът не определя приложимостта на ставката.
- **Доход от наем** — опростена сметка за физическо лице с нормативно признати разходи; има изключения и специални случаи.

Калкулаторите са информационни инструменти и не заместват счетоводен или правен съвет.

## Локално преглеждане

От корена на проекта стартирай стандартния HTTP сървър на Python:

```bash
python -m http.server 8000
```

Отвори `http://localhost:8000/`. Използвай HTTP сървър, за да може браузърът да зареди `rates.json` чрез `fetch`.

## Данни и поддръжка

Стойностите, използвани от калкулаторите, са в `rates.json`. В `metadata.sources` са записани източниците и датите на последна ръчна проверка. Скриптът `check_rates_simple.py` извежда списък за ръчна сверка; той не проверява законодателството автоматично и не променя файла със ставките.

Проверявай данъчните данни в НАП, осигурителните данни в НОИ и законите/бюджетните документи в Министерството на финансите. Такса смет се проверява в наредбата на съответната община. Не актуализирай `lastVerified`, преди да свериш стойностите с официален източник.

Пусни `verify_rates.bat` в Windows или `verify_rates.sh` в Linux/macOS, за да отвориш официалните източници и да видиш кратък чеклист.
